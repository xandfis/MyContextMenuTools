# Contributing

Contributions are welcome through GitHub issues and pull requests.

1. Describe behavioral changes and their motivation.
2. Keep changes focused and avoid committing generated build output or secrets.
3. Build with `.\scripts\Build.ps1`.
4. Validate configuration changes with `.\scripts\Validate-ToolsConfig.ps1`.
5. Confirm that submitted work can be distributed under the MIT License.

By contributing, you agree that your contributions will be licensed under the repository's [MIT License](LICENSE).
